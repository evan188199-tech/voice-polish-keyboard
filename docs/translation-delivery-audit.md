# 翻译与核对交付审查（云端模拟）

本记录基于独立云分支，不代表 Mac 的 eac788c 已包含这些增量，也不代表 iOS 或真实宿主已验收。

| 路径 | 云端可验证结果 | 实际限制 |
| --- | --- | --- |
| 长按上滑选语、松开 | 手势策略与模拟桥测试为开始录音；后续点击提交 | SwiftUI 触控时序、误触和设备回调未测 |
| 翻译正常／取消 | 模拟 provider、排队和取消有覆盖 | 主应用桥仍硬编码 DisabledTranslationService；无真实翻译服务 |
| 已入队但结束回执迟到 | 同一进程中回执带 job ID 时记为中断翻译，原文待恢复，不自动当作译文 | 回执完全丢失或进程销毁后不能重建任务类型；缺元数据时只能隔离 |
| 翻译结束回执丢失且键盘重建 | 模拟旧/不完整响应进入未知结果核对，不自动插入 | 用户仍需手工处理；无法断言原始目标字段或翻译状态 |
| 重复相同 job 回包 | 同一键盘进程内最近 512 个 job ID 去重 | 进程重建或缓存淘汰后不保证持久去重；无宿主插入回执 |
| 核对候选、编辑、保留及取消 | 纯状态与键盘模型模拟覆盖明确动作、恢复、取消和顺序 | SwiftUI 界面/中文手动编辑/键盘切换未实测；显式插入的是当前字段 |
| 未知目标 | 不能验证时保留结果；明确插入当前字段须用户操作 | 不能证明原目标未变，也不能证明宿主接受插入 |

真实翻译启用需要实现并审核实际服务适配、用户明确启用及隐私/配置、错误恢复与真实设备联调；不能只填配置。当前主应用 `KeyboardBridgeServer` 对翻译请求硬编码 `DisabledTranslationService`，未进行真实服务调用。

Mac 集成后至少验证：录音权限与模型就绪；长按选语松手不停止、再点完成；来电锁屏/断桥/切宿主时取消与恢复；A→B 输入框不误投；连续普通与翻译任务顺序；重开键盘与进程被系统回收；多次确认及宿主拒收。用虚构语音内容记录通过/失败/未测，不记录私人语音或凭据。
