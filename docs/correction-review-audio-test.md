# 口述纠字人工验收草案

本清单尚未执行。只在用户同意的设备和宿主应用中使用虚构姓名，不上传或记录录音；记录系统语言、识别器/模型版本、麦克风、噪声环境和转写是否正确，避免记录私人内容。需先由集成负责人接入确认界面并核验目标输入框绑定。

1. 分别用普通话和粤语自然说出同音姓名及“某名人的某字”说明；先记录 ASR 原始文字，再对照显示的候选。文字夹具不能证明声学识别正确。
2. 口述同音词不带字形说明、重复目标、没有前文目标、候选听起来一样、否定或引用语句，检查不自动猜字，无法确定时支持手动编辑、保留原文和取消。
3. 分别选原字、选候选、手动输入完整结果，核查只有明确使用后才插入一次；不应把纠错说明当成最终整理文本。核查原始转写可恢复。
4. 在确认前切换输入框、切换宿主、关闭键盘、断桥重连；迟到识别结果不得送进新输入框。用户取消后不得插入。
5. 连续两次确认、撤销再选、取消后旧结果返回、多段先后完成，核查没有重复插入、未提交队列不会乱序。撤销不能承诺回滚已发送到宿主的文字。
6. 密码、电话等系统不提供扩展键盘的输入场景应遵守系统限制；不要把模拟结果或未支持的宿主当作通过。

每项分别记“通过、失败、未测”和复现条件；绝不把 mock 文本当成真实语音测试。候选是转写提示，不是声学识别置信证明。
