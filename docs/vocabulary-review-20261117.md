# 中文专有词与拆字说明修复候选

本轮用户反馈触发的检查发现：普通词表此前只影响拉丁文字大小写，界面却宣称可帮助 API；拆字说明不符合既有匹配模式时没有核对状态，主 App 的核对视图也未连接。

候选改动：
- 中文 2–8 字专有词提供本机普通话音近候选，保留原文，由用户选择。不是声学热词，不保证粤语或多音字效果，不全量上传词表。
- 有界处理最多 1000 字转写、128 条候选词和32个建议，缓存单字读音，避免重复昂贵转换。超过范围不推断。
- 拆字说明只触发复核，不凭不可靠 ASR 硬猜字形、删除说明或改写已经插入的文字。主 App 增加核对、编辑及明确点击后本机短期复制入口。
- 将“最终插入”改为“待使用结果”，不把未验证的宿主插入说成完成。
- 修复历史存储忽略注入 UserDefaults 的缺陷。此前实机测试可能留下合成测试记录；没有自动清除任何用户历史。
