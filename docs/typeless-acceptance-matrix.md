# Typeless 对标验收矩阵（增量，不重写）

体验目标参考 Typeless 官方 iOS 产品；OpenTypeless 仅作桌面架构参考，不宣称能力或测量值等同。既有 issues 继续负责，各模块不重复开卡。

| 优先级 / issue | 场景 | 验收与量化证据 | 当前缺口 |
|---|---|---|---|
| P0 #3/#4 | 普通话/粤语/中英混合、地名/人名/数字/否定、口头自我纠正 | 分别保留ASR原始、后处理、确认后结果；固定公开合成文本至少30例，真人授权音频另计；报告错字率及误改数，不用合成替代真人 | 当前候选与规则已测，真人字错率未测；不是声学热词 |
| P0 #9 | 超时、取消、旧会话、乱序/重复、断网 | 已有17项值类型契约与超时/会话原生测试；迟到旧结果和重复消费期望0；失败原文保留率应为100%（限测试集） | 实际宿主插入与多App切换未验 |
| P0 #2/#9 | 润色未调用、失败回落、成功不变、成功更新 | 状态必须对应任务快照；原文/数字/否定保真；只在授权服务启用后请求，记录各阶段耗时p50/p95及样本数 | 本地合成通过，真实服务延迟/质量未测，不宣称达到Typeless |
| P1 #1/#10 | 点击开始/结束、冷启动、热启动、取消、返回键盘、锁屏/中断 | 目标设备及至少两个允许第三方键盘的宿主逐项录入结果；用户明确操作一次只交付一次；记录开始至可输入时间 | 当前仅个人侧载；私有App切换API不具App Store合规证明 |
| P1 #4 | 词库选择、撤销、换服务、离线 | 默认不传词库，逐词授权并绑定服务；请求体不含notes、别名、来源；不同服务不沿用；保守过滤需明确限制 | 真实识别效果未测；选择词不保证模型采用 |
| P1 #1/#5/#10 | 隐私/许可/公开demo | 无私人语音/客户数据/凭据进仓库或外部模型；只选定字段；许可未闭环不发布权重/整个仓库 | C工件传输阻塞；模型与全历史审计未闭环 |

以上数量是后续验收计划，不是已完成数量。完成记录以每次 commit/build、测试命令与结果、真实设备和服务为准。失败样例保留并修复，不为了达到数字删除反例。先稳定主流程，再逐步增加选区编辑、写作和Notion；既有翻译/Notion负责人工作不覆盖。
