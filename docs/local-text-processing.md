# 本地保真整理与恢复（#2）

本轮有可执行的本地规则和 provider mock 测试，尚未验证真实粤语／普通话音频和 iPhone 输入效果。

- 仅在有明确事项/步骤引导语、且“第一、第二……”连续时生成纯文本编号列表；末项的明确“另外预算/注意……”另段。自然长文按三个中文句子一组增加空行，不猜话题、不摘要。
- 短文、无连续枚举、英文、代码/路径/引用保守保留。原 VAD 识别原文另存历史，可复制恢复，不回改已插入的宿主文字。
- 现有用户主动启用的云端路径仍为唯一 provider；没有增加上传来源或默认联网。长文、列表、代码与引用只接受词序/字词相同的格式调整，否则退回本地文本。此校验有意保守，不能证明任意自然语言改写的语义等价。
- 超过 12000 UTF-8 字节的云端输入在请求前拒绝，保留完整本地文本；检测 provider 的 length/max_tokens/content_filter 结束原因，拒绝当作完整结果。没有静默裁掉前缀或尾部。
- 云端失败保留本地结果并在 Bridge 及历史标记；本地规则不宣称与 LLM 语义分段相同。现有短文润色行为仍可能依赖模型，不能保证任意模型从不改动事实。
- FIFO ASR、最多两路云端润色和原序交付沿用现有实现；不跨任务合并或修改宿主，不自动回车/发送。

`./scripts/test_portable.sh` 编译真实文本处理与 provider 实现。URLSession 使用进程内 URLProtocol 虚构响应，不建立网络连接。覆盖例句数字/姓名/期限/单位/否定、长段无列表、空/英文/粤英、繁简、代码/路径/版本、超长不截断、幂等、provider 成功/截断/429 与本地结果保留。真实 ASR、真实云端、Xcode、iPhone 均未执行。
