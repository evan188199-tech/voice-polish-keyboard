# 旅游地名词典与确认（#4）

入口：主 App → 专有词词表 → 旅游地名词典。可增删改、启停、搜索，保存规范名、对应繁体、别名、语言、地区、来源说明与用户核对状态。用户编辑优先；同名不同地区允许并列，同名同地区重复及不对应的简繁写法拒绝保存。

内置仅有一般地理名称，别名和读音留空。它不是完整词库、发音资料或识别率保证。没有引入第三方词库、私人文档、私人来源链接或路线组合。

当前 SenseVoice 的词汇参数用于转写后文本整理，没有验证声学热词偏置。本功能是独立的离线转写后建议层：只匹配用户明确录入的别名，不猜近音、不读定位或宿主全文；未确认时不改正文、不上传整份地名词典。

顺序：同段明确口述纠字 → 本地排版 → 用户原有可选云端（失败回退）→ 地名候选。候选只处理最终当前片段内具体 UTF-16 范围；代码/路径/引用保守跳过。已有正确规范名不因另一个词条的别名而被误改。

键盘遇候选后显示草稿，可确认一处、拒绝、撤销，再由“插入草稿”明确插入。输入框不可用时草稿不清除；“暂不插入”将已确认草稿保存为待恢复结果，后续队列继续等待用户插入或明确跳过。恢复状态可在键盘重建后读取，进程中断时同一草稿不会同时作为候选和保留结果重复恢复。原始 ASR 仍在主 App 历史；不会回改宿主既有文字。

`./scripts/test_portable.sh` 覆盖 CRUD/开关/搜索/重启、空值/重复/简繁冲突、同名地区、多候选、用户拒绝与撤销、指定范围、普通词反例、正确地名、代码与文字混合、原序交付等待确认。模拟“贵林→桂林”来自测试专用的用户别名，不是公开种子或已验证的语音误识别规律。

模拟器构建与回归状态见 `integration-status.md`。真实粤语/普通话音频、iPhone UI 和宿主插入未验证；不能用模拟文本证明识别效果。
